## 4. 契约

**U-17 POST /api/user/ticket**
入参：`order_no, type(1-5), description, evidence_urls[]`
处理：
1. 订单必须属于当前用户（40303）；
2. `evidence_count = len(urls)`；`signed_at = delivered_at`（未送达为 null）；`within_window = RefundRuleEngine.withinComplaintWindow(...)`（damage 看 2h）；
3. `INSERT ticket(status=PENDING, source=USER, ...)`；
4. `INSERT ticket_event(CREATE, USER)`；
5. `afterCommit`：`XADD cr:stream:ticket {ticket_no}`（S14 消费）；
6. 返回 `ticket_no, status`。

**U-18/U-19**：按当前用户过滤；**不返回 `agent_*` 内部字段**（只给状态、处理进展、refund_amount）。

**R-11 异常上报**：`TicketService.create(source=RIDER, type, order_no)` + 订单 `ACCEPTED/PICKED→EXCEPTION`（S07 已有，本步统一入口）。

**A-11 GET /api/admin/ticket/page**：`status/type/page`；含 `agent_category/agent_confidence` 摘要。
**A-12 GET /api/admin/ticket/{ticket_no}**：返回完整 `agent_*` + 引用条款原文（join `policy_doc`）+ `recomputed_refund`（Java 复算）+ 事件流 + 工具/模型调用链（trace_id）。

**A-13 POST /api/admin/ticket/{ticket_no}/resolve**
入参：`refund_type(ORDER_REFUND/COMPENSATION), refund_amount, bear_party(platform/rider), remark`。
处理：
1. `refund_amount > 1000` 且 `role != 2` → 40301；
2. `UPDATE ticket SET status='RESOLVED', refund_amount=?, handler_id=?, resolved_at=NOW() WHERE id=? AND status='REVIEWING'`，影响 0 行 → 40907；
3. `RefundService.create(refund_type, order_id, ticket_id, refund_amount, bear_party, idem_key="ticket-{no}")`；
4. `ticket_event(RESOLVE, ADMIN)`；若 `bear_party=rider` 且 `agent_liable_party=rider` → 信用分 −10（`COMPLAINT`）；
5. `afterCommit`：WS + 站内消息。
**A-14 POST .../reject**：CAS `REVIEWING→REJECTED`，无退款，写事件；重复请求 40907。

**TicketConverter**
```
type 1↔delay, 2↔damage, 3↔lost, 4↔attitude, 5↔other
```
只在这一处转换；Python 只认字符串，DB 只存 tinyint。

**TicketStreamConsumer（本步）**：消费到消息后若 `agent.enabled=false` → `agent_failed=1`，否则留待 S14 实现调用 P-03。

## 5. 实现要点
1. `TicketService.create` 用 `@Transactional`，Stream 在 afterCommit。
2. `within_window` 与 `signed_at` 必须由 Java 预计算（Agent 不碰时间判断）。
3. 工单详情对用户隐藏 `agent_*`：用 `TicketVO` 白名单字段，不用 `BeanUtils.copyProperties` 全量拷。
4. 运营详情里"复算金额"调用 `RefundRuleEngine`（`damage` 用 `damage_level`，`lost` 用 `declared_value`，`delay` 用 `delay_minutes`）。
5. 事件流 action 固定枚举；payload 存关键字段快照。

## 6. 禁止
- 不要把 `agent_*` 返回给学生端。
- 不要让 Agent 直接改 `ticket.status`。
- 不要在工单创建时同步调模型（必须异步）。
- 不要让 `type` 与 `agent_category` 两套值在代码里混用。
