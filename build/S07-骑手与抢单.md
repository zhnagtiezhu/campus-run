## 4. 契约

**Lua `grab.lua`（7 步，原子）**
```
KEYS[1]=cr:order:grab:{no}  KEYS[2]=cr:rider:state:{riderId}  KEYS[3]=cr:order:status:{no}
ARGV[1]=riderId
1) owner = GET KEYS[1]；存在且 owner==riderId → return 5；存在且不同 → return 0
2) online = HGET KEYS[2] online；≠1 → return 2
3) busy = HGET KEYS[2] busy_order_count；>=3 → return 3
4) status = HGET KEYS[3] status；≠WAITING 或 paused=1 → return 4
5) credit = HGET KEYS[2] credit_score；<60 → return 6
6) SET KEYS[1] riderId EX 300; HINCRBY KEYS[2] busy_order_count 1
7) return 1
```

**Java 同步落库（抢单核心）**
```
code = eval(grab.lua)
if code != 1: return fail(code)   // 5 视为幂等成功
rows = UPDATE task_order SET rider_id=?, status='ACCEPTED', accepted_at=NOW(), version=version+1
        WHERE order_no=? AND status='WAITING' AND rider_id IS NULL
if rows == 0:
    DEL grab; HINCRBY busy -1
    回查订单：已被抢→40902；状态非 WAITING→40901
else:
    HSET cr:order:status:{no} status ACCEPTED rider_id {riderId}
    XADD cr:stream:dispatch * type GRABBED order_no ...
    return success
```

**R-03 online**：`online=true` → `HSET cr:rider:state online=1 busy=... credit=...` + `EXPIRE 3600` + `GEOADD` + `SETBIT cr:bitmap:online`；`online=false` 要求在手 0 单。
**R-04 heartbeat**：`GEOADD` 更新位置 + `EXPIRE cr:rider:state 3600`（**必须续期**）。
**R-05 hall**：`GEOSEARCH` 1500m + Pipeline 过滤离线/满单/信用<60 + 打分排序；不返回用户手机号。
**R-06 grab**：见上；`Idempotency-Key` 必填；限流 `cr:limit:grab` 20/10min。
**R-07 page**：`GET /api/rider/order/page?status=&page=` → 本人订单分页（MP 分页插件）；不缓存列表（docs/05 §3.1）。
**R-08 detail**：接单人可见 `pickup_code`。
**R-09 pickup**：校验骑手/`ACCEPTED`/码；错误计数 `cr:pickup:fail:{no}:{riderId}`；第 1–2 次 40005，第 3 次写 40905 锁 10min；成功→PICKED。
**R-10 deliver**：`PICKED` + 坐标在半径+300m 内 + photo → DELIVERED。
**R-11 exception**：`ACCEPTED/PICKED → EXCEPTION`，建 ticket（简化：直接 insert + XADD），返回 `ticket_no`。
**R-15 cancel-request**：建 type=5 工单，不改状态。

**WS**：`/topic/rider/{riderId}/task`、`/topic/rider/{riderId}/task-removed`、`/topic/order/{userId}`；CONNECT 头 token；`StompAuthInterceptor` 校验订阅 id == 当前用户。

## 5. 实现要点
1. `GrabLuaExecutor` 用 `DefaultRedisScript<Long>`，脚本从 classpath 读，启动时校验 SHA。
2. 失败码映射统一在 `GrabService`：`0→40902, 2/6→40906(未上线/未接单), 3→40903, 4→40901, 5→success`。
3. `grab_record` 异步：Stream 事件 `GRAB_RECORD` 由消费者批量/单条 insert；成功记录可同步写（1 条）。
4. 状态镜像写入失败不影响主流程（日志 + 巡检重建）。
5. `busy_order_count` 在取件/送达时**不递减**，仅在订单完成/取消/改派时递减（S08/S09 实现递减）。
6. WS 推送在 `afterCommit`。
7. 限流返回 42902，并写 `cr:alert:grab:{riderId}`。

## 6. 禁止
- 不要在 Lua 里查 MySQL。
- 不要先返回成功再异步落库（v1.1 的错误）。
- 不要在抢单接口里做 `select` 再 `update`（竞态）。
- 不要给大厅返回用户手机号/详细门牌。
- 不要把 `pickup_code` 放公共缓存 VO。
