## 4. 契约

**U-07 POST /api/user/order/quote**
入参：`category, from_lng/lat, to_lng/lat, weight_kg, expect_deadline, urgent, declared_value?`
校验：类别 1–5；起终点在半径 2000m 内（haversine）；距离 ≤3000m；时间在 07:00–23:00；`declared_value ≤ 50000`；`item_desc/remark` 过禁运词（此接口暂无 item_desc，下单时再校验）；`expect_deadline` 缺省 = now+60min。
出参：`fee_detail{base_fee,distance_fee,weight_fee,urgent_fee,night_fee,total,capped}`、`distance_m`、`quote_token`。
`quote_token`：`cr:quote:{token}` = `{user_id, category, from/to, weight_kg, deadline, urgent, declared_value, fee_detail, distance_m, expire_at}`，TTL 15min。

**U-08 POST /api/user/order**
入参：`quote_token` 或 `draft_id`（二选一）、`item_desc`、`remark`、`address_id?`、`declared_value?`
处理：校验 token 归属与过期；再校验禁运词；`order_no = "CR"+yyyyMMdd+6位`（`IdGen`，唯一索引冲突重试 3 次）；插入 `DRAFT`；`pickup_code` 4 位随机；`fee = base+distance+weight`、`urgent_fee`、`night_fee`、`raise_fee=0`、`urgency_fee=urgent+night`、`total_fee=fee+urgency`；`idem_key` 写库；状态流水 `DRAFT`（from 空）由 SYSTEM 写。
出参：`order_no, pay_amount`。
幂等：`Idempotency-Key` → `cr:idem:order:{user_id}:{key}`；命中返回首次结果。

**U-09 POST /api/user/order/{order_no}/pay**
校验订单属于当前用户、状态 DRAFT；插入 `pay_record(status=0)`；返回 `pay_no, mock_pay_url=/pay/{pay_no}`。

**模拟支付回调** `POST /api/mock-pay/callback`（仅 dev）：`UPDATE pay_record SET status=1,paid_at=now WHERE pay_no=? AND status=0`，影响 1 行才继续：`DRAFT→WAITING(SYSTEM)` + `ZADD cr:zset:timeout score=now+90 member=order_no` + `XADD ORDER_PAID`。重复回调返回 code=0（幂等）。

**U-13 取消（本步只做 DRAFT）**：`DRAFT→CANCELLED(SYSTEM/USER)`，`pay_status` 不变（未支付）。

**PayTimeoutTask**：每分钟 `status='DRAFT' AND created_at < now-15min` → `DRAFT→CANCELLED(SYSTEM)`，`pay_status=3`。

## 5. 实现要点
1. `OrderService.createOrder` 加 `@Transactional`；Redis/Stream 写放 `afterCommit`。
2. 报价与下单必须用**同一份** `quote_token` 里的 `fee_detail`，禁止重新计算（防篡改/价格漂移）。
3. `distance_m` 服务端算（haversine），不信任前端。
4. 订单号生成失败（唯一冲突）重试 3 次，仍失败抛 50001。
5. 状态流水统一走 `OrderStateMachine.requireTransit` + `OrderStatusLog`。
6. `PayTimeoutTask` 用 `@Scheduled(fixedDelay=60000)`；SQL 带 `status='DRAFT'` 条件。

## 6. 禁止
- 不要在事务里 `XADD`/`ZADD`/发 WS。
- 不要用前端传的 `distance_m`/`total_fee`。
- 不要把加急/夜间塞进 `raise_fee`。
- 不要用 `System.currentTimeMillis()` 拼订单号（会重复）。
