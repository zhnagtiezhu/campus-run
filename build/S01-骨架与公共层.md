# S01 · 骨架与公共层

## 1. 目标
搭出可编译、可启动、可统一返回/统一异常的 Java 骨架，后续所有代码都往这套壳里填。

## 2. 前置
S00 完成：`mvn -v`、JDK 17、MySQL 22 表可连。

## 3. 产出文件

```
backend-java/src/main/java/com/campusrun/
├── CampusRunApplication.java
├── common/
│   ├── Result.java                 # code/message/data/trace_id
│   ├── PageResult.java             # total/page/page_size/records
│   ├── ErrorCode.java              # 枚举，31 个（见下）
│   ├── BizException.java           # code + message
│   └── util/{JwtUtil,IdGen,GeoUtil,EncryptUtil}.java
├── context/

│   └── TraceIdHolder.java          # ThreadLocal + MDC

    ├── application.yml

## 4. 契约

**ErrorCode（31 个，与 `03` §9 一一对应）**：
`SUCCESS(0)`、`PARAM_INVALID(40001)`、`OUT_OF_RANGE(40002)`、`FORBIDDEN_ITEM(40003)`、`QUOTE_EXPIRED(40004)`、
`PICKUP_CODE_ERROR(40005)`、`OUT_OF_SERVICE_HOURS(40006)`、`DECLARED_VALUE_EXCEEDED(40007)`、`RAISE_FEE_PER_LIMIT(40008)`、
`UNAUTHORIZED(40101)`、`TOKEN_EXPIRED(40102)`、`ROLE_FORBIDDEN(40301)`、`AGENT_TOOL_FORBIDDEN(40302)`、`RESOURCE_FORBIDDEN(40303)`、
`NOT_FOUND(40401)`、`DRAFT_EXPIRED(40402)`、`ORDER_STATUS_CONFLICT(40901)`、`ORDER_ALREADY_GRABBED(40902)`、`RIDER_BUSY(40903)`、
`IDEM_CONFLICT(40904)`、`PICKUP_CODE_LOCKED(40905)`、`RIDER_UNAVAILABLE(40906)`、`TICKET_ALREADY_HANDLED(40907)`、`RAISE_FEE_TOTAL_LIMIT(40908)`、
`RATE_LIMITED(42901)`、`GRAB_FREQUENCY(42902)`、`SYSTEM_ERROR(50001)`、`AGENT_UNAVAILABLE(50002)`、`CACHE_INCONSISTENT(50003)`、
`VECTOR_UNAVAILABLE(50004)`、`AGENT_BUDGET_EXCEEDED(50005)`。

**Result**：`Result.ok(data)` / `Result.fail(ErrorCode)`；`trace_id` 由 `TraceIdHolder` 自动填。

**LoginContext**：`set(userId, role)`、`getUserId()`、`getRole()`、`clear()`（拦截器 finally 调）。

**Jackson**：`PropertyNamingStrategies.SNAKE_CASE`；`Long` 序列化为 String（防前端精度丢失）；`LocalDateTime` 用 `yyyy-MM-dd'T'HH:mm:ssXXX`。

**MetaObjectHandler**：insert 填 `createdAt/updatedAt/deleteFlag`，update 填 `updatedAt`（实体字段用 `@TableField(fill=...)`）。

## 5. 实现要点

1. `pom.xml` 依赖只从 `04` §5 取；父版本 3.5.x；只引 `spring-boot-starter-web/validation/aop`、`mybatis-plus-spring-boot3-starter`、`mysql`、`redis`、`redisson`、`jjwt`、`knife4j`、`lombok`、`hutool`、`minio`。
2. `TraceIdFilter`：读 `X-Trace-Id`（32 hex）否则生成，写 MDC + response header，finally clear。
3. `GlobalExceptionHandler`：`BizException`→其 code；`MethodArgumentNotValidException`→40001 + 字段名；其他→50001 + ERROR 堆栈（带 traceId）。
4. `application-dev.yml`：数据源、Redis、JWT（secret 32 位）、`app.encrypt.mode=noop`、`app.agent.enabled=true`、`app.policy.version=1.1`。
5. 写一个 `HealthSmokeTest`（`@SpringBootTest` + MockMvc）或临时 `CommandLineRunner` 打印 "started"，确认上下文能起。

## 6. 禁止
- 不要引入 `spring-boot-starter-security`（三端 JWT 自己写拦截器）。
- 不要在 `Result` 里用 camelCase（全局 snake_case 会转，但别手写 `traceId`）。
- 不要把 ErrorCode 写成字符串常量散落各处。
- 不要在 `domain` 包里 import Spring（S02 会检查）。

## 7. 验收

```
