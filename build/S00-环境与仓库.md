# S00 · 环境与仓库

## 1. 目标
把仓库、依赖、数据库、编排跑起来，做到"一条命令起 MySQL/Redis/MinIO，22 表 + 38 PASS"。

## 2. 前置
无。先读完 `docs/10` §1–3、`docs/14` §2。

## 4. 契约

- compose 六服务：mysql(3306)、redis(6379)、minio(9000/9001)、java-app(8080)、agent-app(8000)、nginx(80)。
- 全部 `TZ=Asia/Shanghai`；MySQL 挂 `./data/mysql`，Redis 开 AOF `everysec`，MinIO 私有 bucket。
- `.env.example` 变量：`MYSQL_ROOT_PASSWORD`、`LLM_BASE_URL/KEY/MODEL`、`AGENT_TOKEN`、`AMAP_KEY`、`JWT_SECRET`、`MINIO_*`。
- `AGENTS.md` 内容照 `docs/14` §2 的 10 条。

## 5. 实现要点（顺序）

1. `git init` + 目录 + `.gitignore`（`.env`、`target/`、`node_modules/`、`data/`、`models/`、`*.log`）。
2. 写 `AGENTS.md`（10 条铁律），先提交。
3. 写 `docker-compose.yml`：mysql 挂 init 目录、healthcheck `mysqladmin ping`；redis `--appendonly yes`；minio `server /data --console-address ":9001"`；java/agent 用 `profiles: ["app"]` 先不启动；nginx 挂 `./nginx.conf`。
4. 写 `.env.example`，不要写真实 key。
5. `docker compose up -d mysql redis minio` → 等 mysql ready → 跑 `verify-demo-data.sql`。
6. 建空 Maven 工程（`pom.xml` 先只放 parent + 打包插件），确认 `mvn -v` 与 JDK 17。

## 6. 禁止
- 不要把 MySQL/Redis 端口暴露到公网；不要给 MinIO 设 public-read。
- 不要在 compose 里写死 LLM key。
- 不要 `docker compose down -v` 之外的方式删 `./data`。

## 7. 验收

```bash
docker compose -f deploy/docker-compose.yml config >/dev/null && echo OK
docker compose up -d mysql redis minio
docker compose logs mysql | grep "ready for connections"
mysql -h127.0.0.1 -uroot -p123456 campus_run < tests/sql/verify-demo-data.sql   # 38 PASS
mysql -h127.0.0.1 -uroot -p123456 -e "select count(*) from campus_run.task_order"  # 7
```
