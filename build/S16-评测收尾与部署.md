## 4. 契约

**eval/run.py**
```
python -m eval.run --set order|ticket|dispatch|attack|all --model <name>
```
- 逐条调 Agent（不经前端），记录 `trace_id/model/prompt_version/latency`；
- 按 `eval/README.md` §2 判分；
- 输出 CSV + 控制台汇总（10 个指标）。

**报告指标**：见 `eval/README.md` §3，全部必须有实测值，禁止编造。
**压测报告**：场景 A（成功数/RT/P99）、B（QPS 倍数）、C（重建次数/DB QPS）。
**README**：架构图 + 快速开始（4 条命令）+ 演示账号 + 三组数据 + 目录说明。

## 5. 实现要点
