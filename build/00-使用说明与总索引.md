# build/ · AI 施工图总索引

> 这不是设计文档，是**给 AI 的作业单**：每一步做什么、产出哪些文件、必须满足什么契约、怎么验收、Prompt 怎么复制。
> 设计依据：`docs/00`~`docs/14`。冲突时以设计文档为准，并回头改本目录。
> 使用前先读 `docs/14-AI辅助开发工作流.md`，并在仓库根建好 `AGENTS.md`。

---

## 1. 使用方式（四步循环）

1. 打开 `Sxx`，把「可复制 Prompt」整段贴给 AI；
2. 让它先输出**文件清单 + 实现计划**，你对照「产出文件」确认；
3. 按「实现要点」逐个文件生成，一次一个文件；
4. 跑「验收」里的命令，全绿才在本页勾掉，进入下一步。

**不要跳步**：S02 的领域层没绿就写 Service，后面一定返工。

## 3. 每步的固定结构

每个 `Sxx` 文件都包含：

```
1. 目标（一句话）
2. 前置（上一步必须绿）
3. 产出文件（精确路径，含包名）
4. 契约（表字段 / 接口出入参 / 类签名 / Redis key）
5. 实现要点（顺序、事务、并发、降级）
6. 禁止事项（最容易犯的错）
7. 验收（命令 + 用例编号）
8. 可复制 Prompt（贴给 AI）
9. 进度（勾选框）
```

```text
每次只写一个文件；写完告诉我验收命令。
```
