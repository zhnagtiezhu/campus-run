## 4. 契约

### 4.1 OrderStateMachine
```java
public final class OrderStateMachine {
    public enum OrderStatus { DRAFT, WAITING, ACCEPTED, PICKED, DELIVERED, COMPLETED, EXCEPTION, CANCELLED }
    public enum OperatorType { USER, RIDER, ADMIN, AGENT, SYSTEM }

    public static boolean canTransit(OrderStatus from, OrderStatus to, OperatorType op);
    public static void requireTransit(OrderStatus from, OrderStatus to, OperatorType op); // 非法抛 40901
    public static boolean isTerminal(OrderStatus status);
}
```
迁移矩阵**严格按 `02` §3.1**：DRAFT→WAITING 只 SYSTEM；ACCEPTED→WAITING / EXCEPTION→WAITING 只 ADMIN/AGENT；同状态只 SYSTEM/AGENT；COMPLETED/CANCELLED 终态。

### 4.2 PriceCalculator
```java
public record FeeDetail(int baseFee, int distanceFee, int weightFee,
                        int urgentFee, int nightFee, int total, boolean capped) {}

public static FeeDetail calculate(int distanceM, double weightKg, boolean urgent, LocalDateTime orderAt);
```
- base=300；distanceFee=`d<=1000?0:ceil((d-1000)/500)*50`；weightFee=`w<=2?0:ceil(w-2)*100`
- urgent=200；night=100（21:00–06:00，左闭右开）
- total=min(2000, base+d+w+u+n)；`capped = raw > 2000`
- 全部 int；用 `Math.ceil` 后转 int，禁止浮点累加

### 4.3 RefundRuleEngine
```java
public final class RefundRuleEngine {
    public enum DamageLevel { LIGHT, MEDIUM, SEVERE }
    public static int delayRefund(int totalFee, int delayMinutes);      // ≤15:0; ≤30:20%; >30:50%; cap 1000
    public static int damageRefund(int totalFee, DamageLevel level);    // 30/60/100%; cap 20000
    public static int lostRefund(int declaredValueCent);                // min(declared,20000)
    public static boolean needsSupervisorApproval(int refundAmount);     // >1000
    public static boolean withinComplaintWindow(long minutesSinceSigned, String ticketType); // damage ≤120
}
```
全部向下取整（`Math.floorDiv`）。

### 4.4 RiderScoreCalculator

public static int onTimeDelta(int todayGained);   // +2，达到 10 返回 0

## 5. 实现要点

1. 先跑 `mvn -q -Dtest=PriceCalculatorTest test`，让它红，再写实现。
2. `OrderStateMachine` 用 `Map<OrderStatus, Map<OrderStatus, Set<OperatorType>>>` 或 switch；`requireTransit` 复用 `canTransit`，失败抛 `new BizException(ErrorCode.ORDER_STATUS_CONFLICT)`（code 40901）。
3. `PriceCalculator` 的 `capped` 表示"原始合计 >2000"，封顶后 total=2000。
4. `RefundRuleEngine` 的 damage 不乘申报价值（上限由 Java 调用方按 `min(实付, 申报或50000, 20000)` 再截断一次）。
5. 所有方法 static、无状态、无 IO。

## 6. 禁止
- 不要用 `double`/`BigDecimal` 做金额累加（`weightKg` 入参可以是 double，但费用计算用 `ceil` 后转 int）。
- 不要让 `requireTransit` 返回 boolean。
- 不要把夜间判断写成 `hour >= 21 || hour <= 6`（6 点整算白天）。
- 不要改测试文件来迁就实现。
