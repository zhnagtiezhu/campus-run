# S04 · 前端骨架与登录

## 1. 目标
三端（student/rider/admin）脚手架 + 登录 + http/ws 封装，能登录、刷新不丢态、mock 首页可点。

## 2. 前置
S03 公共接口可用（至少 C-02/C-03/C-04）。

## 3. 产出文件

```
frontend/
├── pnpm-workspace.yaml
├── package.json
├── shared/
│   ├── api/http.ts
│   ├── api/modules/{auth,common}.ts
│   ├── composables/{useIdemKey,useWebSocket,useCountdown}.ts
│   ├── types/{api,auth,order}.ts
│   └── styles/{variables.scss,index.scss}
├── student-web/{package.json,vite.config.ts,index.html,src/{main.ts,App.vue,router/index.ts,stores/auth.ts,views/Login.vue,views/Home.vue}}
├── rider-web/...（同上）
└── admin-web/...（同上）
```

## 4. 契约

**http.ts**：
- `baseURL='/api'`；request 拦截器加 `Authorization`（按端从 `localStorage` 取 `cr_student_token` 等）+ `X-Trace-Id`（32 hex）。
- 响应拦截器：`code!==0` 抛 `BizError(code,message,trace_id)`；`401xx` 清 token 跳登录；`50002/50004/50005` 弹"智能助手不可用"；`42901` 自动重试 1 次。
- **幂等**：`useIdemKey().get(actionKey)` 生成一次、重试复用、成功后 clear；http 层不自动生成。

**useWebSocket**：`@stomp/stompjs` + `sockjs-client`；`connectHeaders:{Authorization:'Bearer '+token}`；订阅 `/topic/order/{userId}` 等；重连 1/2/4/8/16s 最多 5 次；`onReconnect` 回调。

**路由守卫**：`meta.role` + `meta.public`；无 token → `/login?redirect=...`；角色不符 → 403 页。

**mock**：`vite.config.ts` 的 `server.proxy` 把 `/api`、`/ws` 代理到 `http://localhost:8080`。

## 5. 实现要点

1. `pnpm-workspace.yaml` 包含 `shared`、三端；`shared` 用 workspace 依赖 `@campus-run/shared`。
2. 三端 vite 端口 5173/5174/5175（避免冲突）；`base` 分别 `/student/`、`/rider/`、`/admin/`（与 Nginx 对齐）。
3. 登录页：学生 手机号+验证码（提示 123456）；骑手 手机号+密码；运营 用户名+密码。
4. 登录成功后按端存 token，再 `router.push(redirect || '/')`。
5. 首页先放三张卡片/占位，能点进空页面即可（业务页在后续 Sxx）。
6. `shared/types` 只放与 `03` 一致的字段（snake_case），不要先写 camelCase 再转。

## 6. 禁止
- 不要用 Pinia 持久化插件代替 localStorage（三端 key 必须隔离）。
- 不要在 http 拦截器里自动生成幂等键（会破坏重试幂等）。
- 不要把 token 放 URL query。
- 不要引入 UI 框架之外的组件库（统一 Element Plus）。
