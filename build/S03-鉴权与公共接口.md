## 4. 契约

**JWT**：HS256，secret ≥32 字节，`exp=24h`；claims：`sub`=userId、`role`=USER/RIDER/ADMIN、`aud`=user/rider/admin、`jti`。三端拦截器校验 `role` + `aud` 双重匹配。

| 接口 | 要点 |
|---|---|
| C-01 send-code | 固定 `123456`，`log.info("mock sms phone={} code=123456")`；同一手机号 60s 一次 |
| C-02 user login | `phone_hash=SHA256(phone)` 查；不存在则注册（nickname=同学+随机 4 位）；返回 `{token,user}` |
| C-03 rider login | BCrypt 校验；`status=1 && audit_status=1` 才发 token，否则 40906 |
| C-04 admin login | BCrypt；返回 `{token,admin}` |
| C-05 campus | 1h 缓存；返回 `radius_m/open_time/close_time/forbidden_keywords/default_origins` |
| C-06 upload | 校验 ≤10MB、jpg/png；put 私有 bucket；返回 `{url, expires_at}`（预签名 600s） |
| C-07 health | `select 1` + `redis ping`；返回 `{db, redis, version}` |
| C-08 messages | 按 `LoginContext` 的 `to_type/to_id` 分页；`unread_only` 可选 |
| C-09 read | `UPDATE notify_message SET read_flag=1 WHERE id=? AND to_type=? AND to_id=?`，影响 0 行→40303 |

**路径白名单**：`/api/auth/**`、`/api/common/campus`、`/api/common/health`、`/api/common/upload` 需登录（upload 是）、`/doc.html`、`/v3/api-docs/**`、`/ws/**`。

## 5. 实现要点

1. 三个拦截器只做"解析 token + 校验 aud/role + set LoginContext"，业务不写这里。
2. `afterCompletion` 必须 `LoginContext.clear()`（线程池复用会串用户）。
3. 密码/手机号：dev `app.encrypt.mode=noop`；`EncryptUtil` 提供 `aes()`/`noop()` 两种实现，登录只查 `phone_hash`。
4. MinIO：`MinioClient` bean 从配置注入；预签名用 `GetPresignedObjectUrlArgs`（GET，600s）。
5. 上传文件名用 `UUID + 扩展名`，不要用原文件名（防路径穿越）。
6. 健康检查不要暴露连接串/密码。

## 6. 禁止
- 不要把 `role` 只放在前端；后端必须校验。
- 不要用 `localStorage` 之外的 session 机制（三端同源 localStorage 按端隔离）。
- 不要在登录接口返回手机号明文/密码哈希。
- 不要给 upload 返回永久 URL。

## 7. 验收

