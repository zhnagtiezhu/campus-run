# 03 · 接口设计

> 通信约定：HTTP/JSON ｜ **字段命名一律 `snake_case`** ｜ 金额 `int`（分）｜ 时间 ISO8601（`2026-11-17T17:00:00+08:00`）｜ 鉴权 `Authorization: Bearer <jwt>`
> 服务端口：Java `8080` ｜ Python Agent `8000` ｜ 前端 dev `5173` ｜ 网关 `80`
> 版本：**v1.2**（接口编号有增减，旧编号不复用）

---

## 1. 统一约定

### 1.1 响应结构（Java 侧）

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 0 成功，非 0 见 §9 |
| message | string | 用户可读提示 |
| data | object/array/null | 业务数据 |
| trace_id | string | 全链路追踪，错误时报此值给用户 |

**Python 侧不套这个信封**：`/agent/**` 成功返回业务 JSON + HTTP 200，失败返回非 2xx + `{error_code, message, trace_id}`。这是内部协议，Java 侧统一转换（v1.2 定案，避免"双信封"）。

### 1.2 分页、幂等、状态映射

- 分页统一：`data = { total, page, page_size, records }`，`page_size` 默认 10、上限 50。
- **幂等**：写接口用请求头 `Idempotency-Key`（内部工具由 Python 客户端统一注入）。**key 的粒度是"一次用户动作"**：前端在用户点击时生成并缓存，失败重试复用，成功后清除；服务端按 `scene + user_id + key` 缓存 10 分钟，命中返回首次结果（HTTP 200 + `code=0`）。`40904` 只用于"同 key 但请求参数不同"。
- **订单状态筛选映射**（`status` 查询参数接受分组值或单值）：

| 入参 | 等价状态 |
|---|---|
| `all` | 全部 |
| `waiting` | WAITING |
| `ongoing` | ACCEPTED / PICKED / DELIVERED |
| `finished` | COMPLETED |
| `cancelled` | CANCELLED |
| `exception` | EXCEPTION |
| 大写单值（如 `WAITING`） | 精确匹配 |

## 6. 内部工具接口 `/internal/agent/**`（Python → Java）

**安全**：
- 仅内网；Header `X-Agent-Token`（静态密钥）+ `X-Trace-Id` + **`X-Session-Id`（必填）**。
- **用户身份从 `X-Session-Id` 查 `agent_session.user_id` 派生，工具入参里不接受 `user_id`**（防横向越权）。
- 拦截器校验工具白名单 + 限流（`cr:limit:tool:*`，10 次/10 秒/会话）+ 全量写 `agent_tool_log`（finally）。
- 未注册/禁止的工具（`refund_order`、`update_order_status`）由白名单直接拒绝 → `40302`。

## 8. WebSocket 事件

连接：`/ws`（STOMP over SockJS）；**token 放在 STOMP CONNECT 的 `Authorization` 头**，不放 query（避免日志泄露）。

| 事件 topic | 订阅方 | 载荷 | 触发时机 |
|---|---|---|---|
| `/topic/order/{user_id}` | 学生 | `order_no`, `status`, `rider_masked`, `ts` | 订单状态每次变更 |
| `/topic/rider/{rider_id}/task` | 骑手 | `order_no`, `category`, `from_addr`, `to_addr`, `distance_m`, `fee`, `ttl_sec` | 新单派到推送列表 |
| `/topic/rider/{rider_id}/task-removed` | 骑手 | `order_no`, `reason` | 被他人抢走/超时撤单 |
| `/topic/admin/ticket` | 运营 | `ticket_no`, `type`, `agent_confidence` | 新工单 / Agent 初判完成 |
| `/topic/admin/alert` | 运营 | `type`(TIMEOUT/AGENT_DOWN/GRAB_ANOMALY), `detail` | 告警 |

**订阅鉴权**：`ChannelInterceptor` 校验订阅目的地里的 `user_id`/`rider_id` 与 token 主体一致（运营可订阅 admin topic），否则断开。**不要**使用 `/user/**` 前缀（与 Spring 内置 UserDestination 语义冲突）。

**前端必做**：断线重连（指数退避 1s→16s，最多 5 次）；重连成功后拉一次全量列表兜底。
